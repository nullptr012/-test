# 楚河汉界 · 中国象棋

无需第三方运行时依赖的浏览器小游戏，支持本地双人对弈。红方先行，点击己方棋子，再点击绿色落点；虚线圈表示可以吃的棋子。

## 运行

已生成的 `dist/chinese-chess.html` 是包含全部样式和规则的单文件版本，下载后直接用浏览器打开即可，无需安装或联网。修改源码后可用 Node.js 执行 `npm run build` 重新生成。

在项目目录运行（需要 Python 3）：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

然后在运行该命令的电脑上，用浏览器打开 `http://localhost:8000`。云端运行时需通过平台提供的端口转发访问；本地浏览器的 localhost 不指向云端机器。

也可以安装 Node.js 后使用 `npm start`，效果相同。页面使用 ES modules，请通过 HTTP 服务打开，而非直接双击 HTML 文件。

## 功能

- 自适应桌面和手机屏幕，中文棋盘与棋子。
- 车、马、相／象、仕／士、帅／将、炮、兵／卒的走棋与吃子规则。
- 蹩马腿、塞象眼、炮架、过河、九宫、将帅照面及解将校验。
- 将军提示，将死、困毙与擒将判胜。
- 合法落点提示、走棋记录、逐步悔棋与确认重新开局。
- 不请求外部字体、图片或 API，无需账户或密钥。

目前不包含 AI、网络对战、棋局持久化、重复局面及长将裁定。坐标记录采用从左到右 1–9 列、从上到下 1–10 行。

